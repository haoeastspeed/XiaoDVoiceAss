设备（ESP32 小智）只有一个麦克风、没有回采通道，它播自己的 回复时麦克风会把声音一起传上来，容易被当成「你在说话」而自问自答。 回声消除拿网关自己发出的声音当参考把它减掉；说完后的静默 是等设备播放缓冲和房间混响散掉再开始听。设备自激活太频繁就把静默 调长；反过来打断不灵/第一句老被吃掉就调短。改完自动重启网关生效。
ws://127.0.0.1:8000/
网关是语音识别 / 大模型 / 语音合成的本地服务，打开软件会自动启动并加载离线模型（「重启」会先结束当前聊天再重新拉起，改了模型/音色/接入方式后可点它）。ESP32 等设备的配网页里填上面的本机地址（同一 Wi-Fi 下可达）。设备连不上时依次检查：网关「运行中」→「局域网可连」→ Windows 防火墙是否放行该端口。
语言模型
本地用 Ollama（离线可用）；在线支持任何 OpenAI 兼容端点 —— DeepSeek、阿里百炼、智谱 ChatGLM、Kimi、硅基流动都走同一套协议。 切到在线后会走网络，回答更快但不再离线可用。
记忆
「超长记忆」保留完整对话；「本地总结」把较早的对话压成摘要 再继续（长时间聊也不卡）；「无记忆」每句话都独立，不留上下文。
识别语言
识别模型原生支持普通话、粤语、英语、日语、韩语。 指定语种比「自动判断」更准，但其它语种就基本识别不出来了。
声音
在线音色联网合成、断网自动换本地；离线音色直接本机合成——引擎跟随音色自动选择，无需单独设置。
联网搜索
开启后，遇到天气、新闻、最新事件等实时问题，小D 会先联网查资料再回答；闲聊不受影响。
人设
智能家居（HomeAssistant）
开启后，说「把客厅灯关了」这类话会先识别成家居指令并直接控制 设备，不再走一轮闲聊。令牌只在本地配置文件里，不上传任何地方。
工具与扩展（MCP / 视觉 / 唤醒词）
开启后，联网搜索 / 智能家居 / MCP 工具都交给大模型自己决定何时 调用，能力更强；模型较小或对稳定性要求高时可以先关着（关着时行为与原来 完全一致）。改动后需重启网关生效。
允许设备端（手机/ESP32/本机客户端）把自身能力注册成可调用 工具，也支持接入第三方 MCP 服务（在配置文件的 mcp_servers 里填写）。
选「唤醒词」后需要先安装 openwakeword（可选依赖）；未安装时 自动降级为打开即听，不会影响正常使用。
交互
休眠只是不再预热模型（让它能被系统回收、省内存）， 随时说一句话或点「开始聊天」就能立刻唤醒，不会漏听。
「语音打断」靠麦克风音量判断你是插话还是本机回声：外放时回声 可能盖过人声，建议戴耳机或靠近麦克风；拿不准就用按钮 / Esc，任何模式下都有效。
双击主界面空白处可在全屏显示与窗口显示之间切换，Esc 随时打断说话。
外放觉得吵、或耳机里太小声时拖动调整；只影响小D的说话音量， 不影响麦克风采集。
